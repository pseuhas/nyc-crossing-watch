# MTA source boundary and next feed checks

This is a private no-deploy candidate. The [MTA feed terms](https://www.mta.info/developers/terms-and-conditions) require app users to get the feed from a non-MTA server, disallow directly serving users from an MTA server, and require a notice when the app's realtime data is more than one minute delayed. Review the linked license requirements before public distribution. The root and Island HTML now remove upstream MTA from connect-src. The subway and bus adapters request only project-relative cached JSON and reject redirects. Missing, non-JSON, stale, or failed endpoints cannot become a fresh empty feed. Existing official alert and stop links remain. Demo still makes no feed calls. This does not add a cache, change current production, or confirm legal signoff.

Future cache gate: serve raw MTA JSON from project-relative feeds/mta-subway.json and feeds/mta-bus.json through an app-operated host; one provider poll per dataset, not one per visitor. Validate before making an atomic snapshot available, keep the original source timestamp, distinguish last successful fetch from source time, never proxy cross-origin redirects, apply rate limits and backoff, and verify the endpoint and degraded states on the exact deployment. For links-only rollout leave these paths absent and verify users see unavailable with operator links, not an all-clear. Don't commit to public main before the separate visual checks.

## Upgrade 1: Nearby observed water level, lowest legal and technical friction

- [NOAA Central Station](https://www.tidesandcurrents.noaa.gov/waterlevels.html?id=8518750) confirms Battery gauge 8518750; [official API contract](https://api.tidesandcurrents.noaa.gov/api/prod/) gives six-minute measurements and date=latest capped to last 18 minutes. [NOAA disclaimer](https://www.tidesandcurrents.noaa.gov/disclaimers.html) says public domain unless separately marked; the station itself cautions raw preliminary measurements are not quality-assured official values.
- Exact query parameters: date=latest, station=8518750, product=water_level, datum=MLLW, time_zone=gmt, units=english, application=RooseveltIslandNow, format=json. Check metadata.id, UTC observation time, finite signed height and any quality flag, with bounded timeout. Age from observation rather than download, no value on wrong station, empty or stale response, and no substitute from a predicted tide. Initially label “Observed at The Battery · preliminary · ft MLLW”; separate visually from Queensboro Bridge high/low predictions. No cross-station subtraction, local flood inference, or navigation advice.
- Station/data contract verified; live JSON payload/CORS and recent-stamp soak not verified. Keep gated until one authorized real body + successful browser-origin request, playable outage fixtures, and 24-hour cadence/availability check. Mocking does not establish public rendering.

## Default links-only implementation

Both HTML entrypoints ship with `data-mta-cache="off"`, so the app makes no transit feed requests, not even repeated missing local requests. Only switch both markers to `on` after validating the corresponding app-operated cache. Never add the upstream MTA host to either CSP or a browser fetch. GitHub Actions publishes to Pages automatically from main after test success: review only on a non-main branch, and do not merge while browser QA, rights review, or an explicit publication instruction is missing.
